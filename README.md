# Makine Öğrenmesi Ara Ödev: Müşteri Ayrılma (Churn) Tahmini

## Projenin Amacı
Bu proje, makine öğrenmesi dersinde işlenen temel uçtan uca veri bilimi akışını pratik etmeyi amaçlamaktadır. Sentetik olarak üretilen bir müşteri veri seti üzerinde veri okuma, eksik değer doldurma, kategorik değişken kodlama (One-Hot), ölçekleme ve yeni öznitelik üretimi adımları gerçekleştirilmiştir. Veriler Train, Validation ve Test olmak üzere üç kümeye ayrılarak sınıflandırma modelleri eğitilmiş ve kıyaslanmıştır.

## Nasıl Çalıştırılır?
1. Depoyu bilgisayarınıza klonlayın.
2. Gerekli Python kütüphanelerini kurmak için terminalde şu komutu çalıştırın:
   pip install -r requirements.txt
3. Projeyi çalıştırmak için alttaki komutu çalıştırın: 
python churn_prediction.py
